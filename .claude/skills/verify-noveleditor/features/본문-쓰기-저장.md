# 본문 쓰기와 저장

선택한 회차의 본문을 고치고, 그것이 디스크 `episodes/<id>.md`에 원자적으로 저장되는지.

## Sub-features

- 본문 입력 (글자 수가 사이드바 줄과 아래 상태 줄에 바로 반영)
- `파일 > 지금 저장`
- 자동 저장 (입력을 멈춘 뒤 잠시 후)

## How to get to it (user POV)

작품을 열면 첫 회차가 선택되어 본문이 보인다. 본문을 클릭하고 쓴다.

## Driving it with computer-use

1. `app_screenshot` → 사이드바 `1화` 줄의 글자 수(예: `296`)를 적어 둔다.
2. 본문 마지막 줄 아래 빈 곳을 `app_click`(결과에 `moved to end of text`) → `app_type " 검증표시VERIFY01"`.
3. `app_screenshot` → `1화` 글자 수가 늘었는지, 아래 상태 줄에 글자 수가 보이는지.
4. `app_menu ["파일", "지금 저장"]`.
5. `grep -l VERIFY01 "build/verify/run/검증 작품.novel/episodes/"*.md` → `dummy-0001.md`가 나와야 한다.
6. `verify.sh evidence save-now`.

자동 저장을 볼 때는 4번을 건너뛰고 몇 초 기다린 뒤 5번을 한다. 그래도 없으면 실패로 보고한다(기다리는 시간을 늘려서 통과시키지 않는다. 기준은 `docs/SPEC.md`).

## Gotchas

- 더미 회차 파일 이름은 `dummy-0001.md`처럼 고정이다. 새로 만든 회차는 다른 이름 규칙을 따른다.
- `app_type`은 완성된 글자를 한 번에 넣는다. 한글 조합 중 저장·커서 문제는 여기서 재현되지 않는다(`docs/checklist-hangul.md`).
- 본문 전체를 대화로 읽지 말고 표시 문구만 grep한다.
