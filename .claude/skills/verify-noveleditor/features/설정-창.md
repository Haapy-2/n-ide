# 설정 창

일반·편집기·커서·단축키 탭(사이드바 설정은 일반 탭의 "사이드바" 묶음). 값은 UserDefaults에 저장된다. 그래서 검증 전에 백업하고 정리할 때 되돌린다(`verify.sh`가 처리).

## Sub-features

- 편집기: 글꼴 크기, 줄 간격 같은 본문 모양
- 커서: 커서 모양과 색
- 일반: 테마, 사이드바(글자 수·뒤로 창 비치기), 목표, 스냅샷, 되돌리기, 알림
- 단축키: 메뉴 단축키 바꾸기 (키 입력은 `ShortcutRecorder`가 받는다)

## How to get to it (user POV)

`NovelEditor > 설정…`(⌘,).

## Driving it with computer-use

1. `app_menu {list: "NovelEditor"}`로 설정 메뉴 이름을 확인한 뒤 `app_menu ["NovelEditor", "<그 이름>"]`.
2. `app_list_windows`로 설정 창 window_id를 얻고 그 창을 `app_screenshot`.
3. 탭과 컨트롤을 AX 제목으로 찾아 하나 바꾼다.
4. 작업 공간 창(window_id를 바꿔 지정)을 `app_screenshot`해서 본문에 바뀐 값이 반영됐는지 본다.
5. `defaults read com.haapy2.NovelEditor`로 값이 저장됐는지 확인한다(검증 중이니 사용자 설정이 아니다).

## Gotchas

- 왼쪽 목록의 탭(일반·편집기·커서·단축키)은 백그라운드 클릭(AXPress)으로 바뀌지 않는다. 사이드바 회차 줄과 같은 한계라 화면 승인을 받아 실제 마우스로 누른다. 처음 열면 일반 탭이라 일반은 백그라운드로 본다.
- 팝업 메뉴(드롭다운)는 백그라운드 클릭이 거부된다. 다른 컨트롤을 고르거나, 안 된다고 보고한다.
- 단축키 녹화는 실제 키 입력을 받아야 해서 `app_key`로 안 될 수 있다. 안 되면 사람이 확인할 항목으로 남긴다.
- cleanup을 빼먹으면 바꾼 설정이 사용자에게 그대로 남는다.
