# NovelEditor 기능 지도

검증할 때 사용자가 닿는 기능과, 그것이 됐다는 것을 보여 주는 최종 상태. 기능이 바뀌면 이 지도도 같이 고친다.

| 파일 | 기능 | 증명 |
| --- | --- | --- |
| [본문-쓰기-저장.md](본문-쓰기-저장.md) | 본문 입력, 지금 저장, 자동 저장 | 디스크 `.md`에 입력한 문구가 있음 (2026-11-20 실행 확인) |
| [회차-만들기-전환.md](회차-만들기-전환.md) | 새 회차, 이전·다음 회차, 이름 변경 | 사이드바 줄 수와 `project.json`의 회차 목록 |
| [스냅샷.md](스냅샷.md) | 스냅샷 찍기, 스냅샷 보기 | `snapshots/` 아래 새 파일과 스냅샷 판 |
| [설정-창.md](설정-창.md) | 설정 창 탭(일반·편집기·커서·사이드바·단축키) | 바꾼 값이 편집기 화면에 반영됨 |
