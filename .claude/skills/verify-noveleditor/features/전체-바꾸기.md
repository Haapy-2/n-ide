# 전체 바꾸기·되돌리기

- 진입: 툴바 `작품 전체 검색` → 위 칸(찾을 말)·아래 칸(바꿀 말) → `모두 바꾸기` → 확인 창 `모두 바꾸기`. 되돌리기는 토스트 `되돌리기`(5초 뒤 사라짐) 또는 편집 메뉴 `전체 바꾸기 되돌리기…`(되돌릴 회차가 하나면 창 없이 바로 되돌림).
- 증명: 디스크 `episodes/*.md`와 `snapshots/<회차>/<시각>-replace.md`(바꾸기 전)·`-replaced.md`(바꾼 뒤)·`.memo`의 곳 수, 되돌린 뒤 `-revert.md`.
- 함정:
  - `app_type`으로 찾을 말 칸을 `replace` 모드로 바꾸면 검색이 다시 돌지 않을 때가 있다("찾은 곳이 없어요"). 실제 클릭 → ⌘A → 지우기 → 실제 키로 친다.
  - 확인 창이 닫히면 입력 초점이 확인 창을 열기 전 자리로 돌아간다. `app_click`(AX로 커서만 옮김)은 초점을 옮기지 않으므로, 편집기에 칠 것이면 실제 마우스로 마지막 줄 글 끝 오른쪽을 눌러 둔 뒤 `모두 바꾸기`를 누른다.
