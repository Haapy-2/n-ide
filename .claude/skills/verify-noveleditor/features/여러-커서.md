# 같은 말 여러 커서(⌘D)

- 진입: 실제 마우스로 편집기 글을 눌러 키보드 초점을 준 뒤 ⌘D(`build/verify/keys c2`) 또는 편집 메뉴 `같은 말 하나 더 고르기`. 커서만 있으면 첫 ⌘D는 단어만 고르고, 다음부터 같은 말을 하나씩 더한다. 맨 앞 말고 다른 자리는 회색 바탕(선택)·세로 막대(커서)로 그려진다.
- 증명: 실제 키로 친 글이 모든 자리에 같게 디스크 `.md`에 있음(`tail -n 1 … | sed 's/ /·/g'`로 공백까지). ⌘Z(`c6`)를 끝까지 누르면 고른 상태로 돌아옴.
- 함정:
  - 입력 소스를 앱 밖에서 바꾸면(TIS) 메뉴 막대는 "한"이어도 앱 입력 칸은 계속 영문으로 받을 수 있다. 커서 하나 상태에서 한글이 들어가는지 먼저 보고, 영문이면 편집기를 다시 누른 뒤 커서 하나로 한글을 한 번 쳐 본다. 끝나면 입력 소스를 처음 것으로 되돌린다.
  - 클릭은 여러 커서를 끝낸다. ⌘D 뒤에는 클릭하지 않고 키로만.
  - `app_type`·`app_click`(AX)은 입력기를 거치지 않아 한글 조합 확인에 쓸 수 없다. 글 준비에만 쓴다.
  - 커서 깜빡임은 키 창에서만 보인다. 백그라운드 조작으로는 커서가 늘 꺼져 보이니, 깜빡임을 볼 때만 사용자 허락을 받고 `osascript -e 'tell application id "com.haapy2.NovelEditor" to activate'`로 앞에 띄운 뒤 `app_batch`의 `zoom`을 여러 번 찍는다.
  - 실제 키 도구는 ⌘(c)·⇧(s)만 붙인다(⌥ 없음). 화살표 키 코드: ← 123, → 124, ↓ 125, ↑ 126. ⌘C·⌘V 확인은 사용자 클립보드를 덮어쓰니 먼저 알린다.
