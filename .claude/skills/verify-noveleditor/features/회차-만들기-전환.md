# 회차 만들기와 전환

사이드바의 회차 목록을 다루는 기능. 회차 정보는 `project.json`, 본문은 회차마다 `.md`.

## Sub-features

- 새 회차 (툴바 버튼 `새 회차`, 메뉴 `회차 > 새 회차`)
- 이전·다음 회차 (메뉴 `회차 > 이전 회차`, `다음 회차`, 사이드바 줄 클릭)
- 이름 변경 (`회차 > 이름 변경…`)
- 휴지통으로 이동 (`회차 > 휴지통으로 이동…`). 본문 파일은 지우지 않아야 한다(CLAUDE.md)

## How to get to it (user POV)

작업 공간 창 왼쪽 사이드바. 오른쪽 위 툴바의 `새 회차` 버튼.

## Driving it with computer-use

1. `app_screenshot` → 사이드바 회차 줄 수(검증 작품은 `1화 2화 3화`).
2. `app_click`으로 AX `"새 회차"` 버튼, 또는 `app_menu ["회차", "새 회차"]`. 두 진입로를 모두 해 본다.
3. `app_screenshot` → 줄이 하나 늘고 새 회차가 선택되었는지.
4. 디스크: `ls "build/verify/run/검증 작품.novel/episodes/"`에 새 `.md`, `grep -c '"id"' ".../project.json"`로 회차 수 확인.
5. 전환: `app_click` AX `"2화"` → 본문이 바뀌었는지 화면으로 확인. `app_menu ["회차", "다음 회차"]`도 해 본다.
6. `verify.sh evidence new-episode`.

## Gotchas

- 이름 변경과 휴지통은 시트(대화 상자)를 띄운다. 시트 안 입력이 백그라운드 도구로 안 되면 그 사실을 보고한다.
- 휴지통으로 보낸 뒤에도 `episodes/`의 본문 파일이 남아 있는지 확인한다. 사라졌으면 원고 유실 버그다.
