# 여러 회차 이름 변경과 이름 변경 스냅샷

사이드바에서 여러 회차를 골라 한 번에 이름을 바꾼다(PLAN 15장). 이름이 바뀔 때마다(한 회차·여러 회차·⌘Z·⇧⌘Z·스냅샷 복원) 회차마다 `rename` 스냅샷이 남는다.

## Sub-features

- 우클릭 `N개 회차 이름 변경…` → 창: `글자 바꾸기`, `앞·뒤에 붙이기`, `새 이름 + 번호`, 아래에 `옛 → 새` 목록
- 이름 변경 스냅샷: `snapshots/<회차ID>/<시각>-rename.md` + `.title`(바뀌기 전 제목) + `.memo`(`'1화' → '프롤로그 1' · 3개 회차 함께`)
- 판에서 이름 변경 스냅샷의 메모를 고치면 `이 스냅샷을 지킬까요?` → `지키기`면 `.keep`과 목록의 핀
- 판에서 이름 변경 스냅샷 복원 → 제목도 `.title`로(`제목도 되돌려요: …`, 토스트 `제목도 되돌렸어요`)

## Driving it with computer-use

1. 여러 개 고르기·우클릭은 전체 화면 제어가 필요하다. `computer_batch`의 `left_click`에 `text: "cmd"`로 ⌘클릭, `right_click`으로 메뉴.
2. 한글 이름은 `keys.swift`로 친다(`프롤로그` = `9,46,3,4,3,3,4,15,46`). 마지막 글자 조합 중에 `36`(엔터)으로 적용해 한글 함정을 본다.
3. 디스크: `project.json`의 제목, `snapshots/*/`의 `-rename.*` 파일과 메모.
4. 사이드바 ⌘Z: 회차 줄을 눌러 초점을 준 뒤 `keys c6` → 확인 창 → `되돌리기`. 메모 끝이 `· 되돌림`.
5. 판: `keys cs1`(⇧⌘S). 메모 고치기는 줄을 두 번 클릭.

## Gotchas

- ⇧클릭(`text: "shift"`)은 2026-11-24에 범위가 잡히지 않았다. ⌘클릭을 한 줄씩 쓴다.
- 토스트(5초)는 도구 왕복 사이에 사라지기 쉽다. 되돌리기는 사이드바 ⌘Z로 본다.
- `computer_batch`와 `app_*`를 섞으면 "백그라운드로 잡고 있음" 오류가 난다. 전체 화면 제어 중에는 메뉴도 `keys`로 누른다.
