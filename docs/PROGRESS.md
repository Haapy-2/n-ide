## 사용자 손 확인이 남은 것

실제 앱에서 사용자가 직접 해 볼 것. 끝난 묶음은 지우고 작업 기록에 "손 확인 끝"으로 남긴다.

### 회차 묶음 손 확인
1. 1화를 누르고 3화를 ⌘클릭 → 두 줄 모두 회색. 우클릭 `2개 회차 묶기…` → 이름 입력 → 3화가 1화 바로 아래로 오고 묶음 제목 줄이 생기는지. ⌘Z(사이드바에 초점) → 원래대로.
2. ⇧클릭으로 범위 고르기, 우클릭 `묶음에 넣기 ▸`.
3. 묶음 밖 회차를 묶음 한가운데로 끌어 놓으면 들어가고, 묶음 회차를 밖으로 끌면 빠지는지.
4. 묶음 제목 두 번 클릭 → 이름 변경. 우클릭 `묶음 풀기`. 접고 앱을 껐다 켜도 접혀 있는지.

### 12단계 손 확인
1. ⇧⌘F → 사이드바가 검색 패널로 바뀌고 입력 칸에 커서. **한글을 조합하면서 쳐도 입력 칸 글자가 깨지지 않는지**(치는 중에 결과가 바뀜).
2. 결과를 누르면 그 회차로 가서 문구가 노랗게 표시되고 바로 이어 쓸 수 있는지. 같은 회차 안의 다른 결과도.
3. 본문에 새 문구를 치고 1초 안에 검색 → 방금 친 것도 찾히는지.
4. `Aa`를 켜고 영어 대소문자가 구분되는지. Esc·✕로 회차 목록에 돌아오고, 다시 ⇧⌘F 하면 문구와 결과가 남아 있는지.

### 11f 손 확인
1. ⌘, → 편집기 → "줄 번호 보이기"를 켠다 → 본문 글자가 한 칸도 안 움직이고 왼쪽 여백 끝에 회색 번호가 생긴다. 끄면 사라진다.
2. 긴 문단은 첫 줄에만 번호, 빈 줄에도 번호. 맨 끝에서 엔터를 치면 새 빈 줄에 바로 번호가 붙는다.
3. 중간에서 엔터를 치거나 줄을 지우면 아래 번호가 모두 따라 바뀌고 옛 번호가 남지 않는다. 스크롤해도 번호가 맞다.
4. 창을 좁히면 번호만 사라지고 본문은 그대로.
5. **창이 넓을 때 번호와 문단을 눈으로 잇기 괜찮은지**(A안의 약점) 봐 주세요. 불편하면 거리 값(20pt)만 바꾸면 된다.
6. 한글 체크리스트 15번.
7. ⇧⌘S 비교 화면의 줄 번호와 편집기 번호가 같은 문단을 가리킨다.

### 오른쪽 여백 클릭 손 확인
1. 짧은 줄(예: "여기서 뭐 해요?")의 오른쪽, 본문 칸 바깥 여백을 누른다 → 커서가 그 줄 끝에 온다.
2. 긴 줄의 오른쪽 여백을 누른다 → 그 줄 끝(다음 줄 맨 앞이 아니라)에 온다. 끌어서 선택도 오른쪽 여백에서 시작된다.

### 토스트 손 확인
1. 작품을 열고 몇 글자 친 뒤 ⌘S → 오른쪽 위 툴바 바로 아래에 `✓ 저장했어요`가 유리 바탕으로 뜨고 2초(기본) 뒤 사라진다. 커서는 그대로, 바로 이어 쓸 수 있다. **유리 모양과 자리가 괜찮은지** 봐 주세요(디자인 스냅샷에는 유리가 안 찍힘).
2. 창 폭을 줄이거나 사이드바를 접어도 오른쪽 위에 붙어 있다.
3. ⌃⌘S → `스냅샷을 찍었어요 · 메모 달기`. 그냥 두면 사라지고 메모 창은 안 뜬다. 다시 찍고 `메모 달기`를 누르면 "스냅샷 메모" 창이 뜬다.
4. 토스트 위에 마우스를 올려 두면 사라지지 않고, 내리면 설정한 시간 뒤 사라진다.
5. ⌘, → 일반 → 알림 → 유지 시간을 5초로 → ⌘S → 5초 머문다.
6. ⌘, → 단축키 → "저장하면서 스냅샷 찍기" 스위치를 켠다 → 지금 저장·스냅샷 찍기 칸이 흐려지고 눌러도 녹화되지 않는다. 새 줄 칸은 녹화된다. 작품 창에서 글을 고치고 ⌘S → `스냅샷 저장됨 · 메모 달기`. 고치지 않고 다시 ⌘S → `저장했어요`. ⇧⌘S 판에 스냅샷이 하나만 늘었다. 스위치를 끄면 원래대로. 한글 조합 중("하")에 ⌘S를 눌러도 글자가 깨지지 않는다.

### 11e 손 확인
1. 글을 조금 고치고 ⇧⌘S → 오래된 스냅샷을 골라 `이 버전으로 되돌리기` → 판이 닫히고 본문이 옛 글, 커서가 편집기에 있고 바로 이어 쓸 수 있다. 상태 줄에 `시:분:초 버전으로 되돌렸어요 · 취소`.
2. `취소`(또는 ⌘Z 한 번) → 되돌리기 전 글. 다시 ⇧⌘Z → 옛 글.
3. 다시 ⇧⌘S → 목록 맨 위에 `복원 전`, 메모 "…버전으로 되돌림". 그걸 골라 되돌리면 되돌리기 전 글로 돌아가고 `복원 전`이 하나 더 생긴다.
4. 맨 위(지금과 같은 것)를 고르면 버튼이 흐리고, 마우스를 올리면 "지금 글과 같아요".
5. 되돌린 뒤 2초 기다려 앱을 끄고 다시 열면 되돌린 글이 남아 있다.

## 알려진 문제

- 실제 앱 확인 목록 12번 앞부분: 묶음 맨 앞 회차를 묶음 제목 줄 위에 놓을 수 없다(위 "다음 할 일").
- 작가의 하루 시뮬레이션 테스트가 끝에 테스트 앱을 죽여 기본으로 꺼 둠(PLAN 18장 3번).
- perf.sh 안에서만 전체 바꾸기(2.45~2.88초)·모두 되돌리기(2.86초)가 목표 2초 미달, 앱 실행(523~562ms)도 500ms 경계에서 미달이 잦다. 17단계.
- 찾았지만 드물거나 확인이 필요해 남긴 버그는 PLAN 18장 1번.
- (2026-11-23) 창 실행 취소의 "전체 바꾸기"는 자기 바꾸기가 아니라 "가장 최근에 되돌릴 것이 남은 바꾸기"의 창을 연다(최근 것부터 규칙과 같아 그대로 둠).
- (2026-11-23) 디자인 스냅샷 `11-snapshot-panel`은 "지금" 시각으로 그려져 실행할 때마다 시각 글자만 바뀐다(그림 비교가 늘 바뀜으로 나옴).
- 디자인 스냅샷은 창을 화면 밖에서 그려 뜨는 방식이라 **사이드바(유리 패널과 그 안의 회차 목록)가 통째로 하얗게 찍힌다**. 사이드바는 실제 앱이나 Xcode 미리보기로 확인한다. 자동으로 찍으려면 화면 기록 권한이 필요해서 보류.
- 글자 수가 없는 옛 작품의 회차는 열기 전까지 사이드바 숫자가 비어 있다(2026-11-12).
