## 7단계: 회차 관리 (`85c1f73`)
- **결정**: `ProjectModel`이 회차 목록을 바꾸고 `project.json`을 같은 저장 줄로 저장. 새 회차는 빈 파일 먼저 쓰고 목록에 넣음(목록에만 있고 파일 없는 회차 방지). 휴지통으로 못 옮기면 아무것도 바꾸지 않음(영구 삭제로 대신하지 않음). 지우기 전에 마지막 내용 저장, 지운 뒤 자동 저장이 파일을 되살리지 않게 저장 정보 정리. 회차 메뉴 단축키: 새 회차 ⌘N, 이전/다음 ⌥⌘↑↓, 이름 변경 ⇧⌘R, 휴지통 ⌥⌘⌫. 테스트는 진짜 휴지통 대신 테스트 폴더로 옮기도록 바꿔 끼움.
- **에러 1**: 이웃 회차 이동 명령의 클로저 타입 추론 실패로 빌드 오류 → 별도 함수로 분리.
- **사이드바 ↩·⌘⌫** (`cfa1af6`, 사용자 재시도 요청): 사이드바가 키보드 초점을 받게 하고, 회차 클릭 때 편집기가 초점을 빼앗지 않게. 앱을 처음 열 때는 편집기에 초점(실행 측정으로 확인).
- **에러 2**: ⌘⌫가 안 먹힘(사용자 보고). ⌘ 조합은 macOS가 메뉴에 먼저 보냄.
  - **수정** (`b10d3f8`): 사이드바에 초점이 있을 때만 메뉴 단축키를 ⌘⌫로 바꿈(편집기에서는 ⌥⌘⌫, 편집기 ⌘⌫는 "줄 앞까지 지우기" 유지).
- **순서 변경 되돌리기** (`f480d85`): 사용자 요청. 초점 위치로 되돌리기 기록 분리(사이드바 = 회차 목록, 본문 = 글자).
- **에러 3**: 되돌리기 테스트에서 앱이 죽음. 되돌리기 처리 안에서 다시 실행 기록을 비동기(Task)로 등록해 UndoManager 묶음 밖에서 등록됨.
  - **수정**: 기록은 그 자리에서 동기로, 파일 저장만 Task로.
- **새 회차·휴지통 되돌리기** (`fef925d`): 사용자 요청. 휴지통에서 원래 자리·본문 그대로 꺼냄.
- **회차 사이 틈 클릭 무반응** (`fef925d`): 칸 사이 1pt 틈과 시스템 최소 줄 높이 → 틈까지 클릭 영역에 포함, 최소 줄 높이 0.
- **되돌리기 정책 문서화** (`3e6f8ae`): PLAN 9장(메뉴에 보이기, 전체 바꾸기, 회차 묶음).
- **성능(7단계 측정)**: 키 입력 p95 1.1ms, 회차 전환 2.1ms, 앱 실행 중앙값 460ms(통과, 단 1.1초·약 6분짜리 튀는 값이 한 번씩 — 기기 상태로 추정, 미확인), 대기 메모리 113MB(미달, 17단계).
