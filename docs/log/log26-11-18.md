# 2026-11-18 작업 기록

## 앱 안 토스트 알림 (커밋 해시는 커밋 뒤에)
- **이유**: 사용자 요청 "앱 안 오른쪽 위에 작게 스냅샷 저장 완료, 파일 저장 완료 같은 다용도 알림". 시스템 알림은 아님.
- **근거**: 계획을 먼저 보고하고 사용자가 "추천대로, 3초"로 승인. 추천 두 가지: ① SPEC 5장 "'저장됨' 알림 금지" 때문에 자동 저장에는 안 띄우고 ⌘S 성공 때만, ② 스냅샷 찍기 뒤 메모 창 대신 토스트 `메모 달기`. DESIGN 0장(유리는 조작 층에만, 직접 만드는 유리는 제안 후 기록), 6장(150ms, 동작 줄이기).
- **결과**: (처음 승인은 3초였고 이어서 아래 설정 작업에서 기본 2초로 바뀜) `App/Workspace/Toast.swift`(`Toast`, 창마다 하나인 `ToastCenter`, `ToastOverlay`, `ToastView`). 편집 영역 위에 얹어 안전 영역(툴바 아래) 오른쪽 위에 뜸. 3초, 마우스를 올리면 기다림, 새 알림이 이전 것을 바꿈. `WorkspaceView`의 ⌘S(`saveNow`: 저장 뒤 상태가 `idle`이고 충돌이 없을 때만)와 스냅샷 찍기에 연결. 메모 창 제목은 "스냅샷 메모". 11e의 상태 줄 `되돌렸어요 · 취소`는 그대로 두고 되돌리기에는 토스트를 안 띄움(위·아래로 자리가 달라 겹치지 않고 같은 말이 두 번 안 나옴). 테스트 `ToastTests` 5개, 디자인 스냅샷 `12-toast`. NovelCore 93개, 앱 129개(건너뜀 9) 통과. perf.sh 전부 통과(실행 461.2ms, 대기 메모리 91.0MB). DESIGN 0·4장, SPEC 5장 예외 한 줄.
- **에러**: 처음 타이밍 테스트를 100ms 기준·50ms 여유로 짰다가 기기가 바쁠 때 흔들릴 수 있어 300ms 기준·100ms 이상 여유로 넓힘. 동작 줄이기 때도 흐려지게 했다가 DESIGN 6장("애니메이션 없이 즉시")에 맞춰 바로 바뀌게 고침. 디자인 스냅샷에서 유리 바탕이 안 찍힘(화면 밖 그리기 한계, 8장) → 실제 앱 손 확인으로 돌림.
- 11e(스냅샷으로 되돌리기)가 커밋 안 된 채 같은 `WorkspaceView.swift`·`PROGRESS.md`를 고치고 있어서, 커밋할 때 토스트 부분만 골라 올린다.

## 알림 유지 시간 설정 + 저장하면서 스냅샷 찍기 (커밋 해시는 커밋 뒤에)
- **이유**: 사용자 요청 "알림 유지 시간 0.5~5초, 기본 2초", "⌘S 누르면 스냅샷 저장됨이 뜨면서 파일도 저장(동기화 느낌)", "저장·스냅샷 키는 둘 다 잠겨 녹화 안 되게, 동기화 설정에 전용 키 칸과 왼쪽 토글(기본 끔), 켜면 그 키가 풀림", "설명도 넣어줘".
- **근거**: 계획을 여러 번 고쳐 올려 사용자 "ㄱㄱ". 직접 찍은 스냅샷은 보관 개수 정리에서 지워지지 않아서, 같은 글이면 건너뛰기를 추천(사용자 이의 없음). NovelCore `writeSnapshot(skipIfSameAsLatest:)`가 이미 있어 그대로 씀.
- **결과**:
  - 알림: `AppSettingKey.toastDuration`, `EditorSetting.toastDuration`(0.5...5, 0.5 단위, 기본 2). `ToastCenter`가 띄울 때마다 설정을 읽음(`storedDuration`). 일반 탭 맨 아래 "알림" 묶음.
  - 저장하면서 스냅샷: `ShortcutCommand.saveWithSnapshot`(기본 ⌘S), `ShortcutSettings.savesWithSnapshot`(저장 글에 `@savesWithSnapshot` 줄), `isActive`(지금 저장과 둘 중 하나만), `isLocked`, `saveMenuShortcut`, 문제 종류 `usedByLocked`, 켜고 끌 때 새로 쓰이는 쪽 키가 다른 명령과 겹치면 비움. 단축키 탭 줄에 스위치·설명·잠금(흐림 0.45, 녹화·기본값 버튼 막음). 메뉴 "지금 저장"이 켜지면 그 키로 `saveWithSnapshot`. `EpisodeSnapshotter.takeManual`·`EpisodeAutosaver.takeManualSnapshot`에 `skipIfUnchanged`. 저장이 실패·충돌이면 찍지 않음.
  - 테스트: 단축키 4개(잠금, 저장 글·모두 기본값, 문제 판정, 끌 때 겹치는 키 비우기), 메뉴 반영 1개, 같은 글 건너뛰기 1개, 유지 시간 맞추기 1개(3초 기다리던 테스트를 대신함). NovelCore 93개, 앱 135개(건너뜀 9) 통과. perf.sh 통과. 디자인 스냅샷 `10-settings-general`, `10-settings-shortcuts`.
- **에러**: `storedDuration`을 `nonisolated`로 했다가 `EditorSetting`이 MainActor라 빌드 실패 → 빼고 메인에서만 부름. 기본 단축키 겹침 테스트(`testDefaultsHaveNoClashes`)는 그대로 두면 지금 저장·저장하면서 스냅샷 찍기의 같은 ⌘S 때문에 실패할 것이라 미리 → 둘은 동시에 쓰이지 않으므로 "쓰이는 명령끼리" 보도록 테스트 규칙을 바꿈(켬·끔 둘 다 확인). 잠긴 칸이 `.disabled`만으로는 흐려 보이지 않음(칸 글자가 .primary) → 따로 흐리게.
- **남은 것**: 일반 탭 스냅샷 설명의 "직접 찍은 것(⌥⌘S)"이 지금 기본값 ⌃⌘S와 다름(이번 작업 전부터). 이번 커밋에는 안 넣음.
- `EpisodeAutosaver.swift`·`EpisodeSnapshotter.swift`도 11e가 고친 파일이라 커밋 때 이번 줄만 골라 올린다.
