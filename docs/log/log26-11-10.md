## 1단계: 앱 뼈대 (`d87daa5`)
- **이유**: 빌드되고 실행되는 최소 틀.
- **근거·결정**:
  - Xcode 프로젝트는 직접 작성, "폴더 동기화 그룹" 사용 → `App/`에 파일을 넣으면 자동 포함. XcodeGen은 Homebrew 설치가 필요해 제외.
  - 최소 macOS 27, Swift 6 모드(데이터 경쟁을 컴파일러가 잡음), 앱 기본 격리 MainActor.
  - NovelCore는 macOS 27 + iOS 27 둘 다 지원 대상 → macOS 전용 API가 섞이면 바로 컴파일 오류.
  - 색 값은 `Colors.xcassets` 한 곳(라이트/다크 나란히 보임, iOS에서도 재사용).
  - Pretendard Regular만 번들(서식이 없어 다른 굵기 불필요), `ATSApplicationFontsPath`로 코드 없이 등록.
- **에러 1**: NovelCore 테스트가 앱 스킴에서 실행되지 않음(패키지 테스트 참조가 무시됨).
  - **수정**: `test.sh`가 NovelCore는 `swift test --scratch-path build/spm`으로 따로 돌림.
- **에러 2**: `xcodebuild` 결과 묶음이 홈 폴더 임시 위치에 생김(폴더 밖 파일 금지 규칙).
  - **수정**: `-resultBundlePath build/logs/…` 추가.
- **에러 3**: 스냅샷 테스트가 끝난 뒤 앱이 죽음(NSWindow 이중 해제).
  - **수정**: `window.isReleasedWhenClosed = false`.
- **에러 4**: Xcode가 색 이름 `accent`와 `AccentColor`로 같은 기호를 자동 생성하려 해 경고.
  - **수정**: `ASSETCATALOG_COMPILER_GENERATE_ASSET_SYMBOLS = NO`, 색 이름은 `ColorTokens.swift`에서 직접 관리.
- **한계**: 스냅샷은 창을 화면 밖에서 그려 리퀴드 글래스 사이드바가 하얗게 찍힘 → 사이드바는 실제 앱/미리보기로 확인.

## 2단계: 저장 기본 (`efc83d6`)
- **이유**: 원고 유실이 가장 심각한 버그(SPEC 6장).
- **결정**: 원자적 쓰기 = 같은 폴더 임시 파일 → `fsync` → `rename`. 고유 ID(UUID 소문자) 파일 이름. `project.json`은 사람이 읽기 쉽게 들여쓰기·키 정렬. 버전부터 읽어 더 새 형식은 고치지 않고 거부. 본문은 UTF-8 그대로(BOM만 제거), 파일이 없거나 UTF-8이 아니면 빈 회차로 넘기지 않고 오류.
- **결과**: 테스트 22개. 저장 실패(폴더 읽기 전용)에도 원본 유지 확인.

## 3단계: 저장 순서와 복구 (`f9d254e`)

## 4단계: 작품 선택 창, 사이드바, 성능 도구 (`946a49c`)
- **결정**: Info.plist에 `.novel` 패키지 등록. 저장·열기 창은 SwiftUI에 대응이 없어 AppKit을 `SystemDialogs.swift` 한 파일에만(규칙 예외, CLAUDE.md 기록).
- **사용자 요청**: 더미 작품을 전부 5,000자로 만들지 말 것(토큰 절약) → 앞 10화만 5,000자, 나머지 300자. 생성 파일 내용은 대화로 읽지 않기로.
- **에러 1**: 스냅샷에서 사이드바 목록까지 통째로 하얗게 나옴(유리 층 밖이라 캡처 불가).
- **에러 2**: 화면 제어 권한(computer-use) 요청이 이 원격 작업 방식에서 표시되지 않아 실패. 여러 번 시도 후 중단 → 사용자가 직접 확인(500회차 표시, 여닫기 정상).
- **에러 3**: `test.sh` 요약이 "0 tests"로 잘못 나옴(XCTest 성능 타깃 줄을 집음).
  - **수정**: 가장 큰 숫자 줄을 고르도록 정렬.
- **결과**: 500회차 열기(파일 읽기) 0.8ms / 목표 300ms.

## 5단계: 편집기와 한글 입력 (`ab0e1b7`)
- **결정**: `NSTextView`(TextKit 1 명시). 본문 폭 고정(40자×글자 크기), 줄 높이 고정, 아래 여백 = 보이는 높이 절반. 본문 원본은 텍스트 저장소, `updateNSView`에서는 회차가 바뀔 때(token)만 본문을 넣음. 조합 중에는 모양 적용도 하지 않음. 회차별 실행 취소 기록.
- **결과**: 키 입력 p95 1.2ms, 회차 전환 2.2ms. 한글 손 확인 체크리스트(`docs/checklist-hangul.md`).
- **에러(성능 미달)**: 앱 실행 718ms(목표 500), 대기 메모리 129MB(목표 100).
  - **조사**: 메모리는 원고와 무관(500회차·1회차·선택 창만 띄워도 비슷). 큰 덩어리는 그래픽 버퍼와 출처 미상 50MB.
  - **결정**: 사용자 C안 — 17단계에서 다시 본다(`0e3240a`). 사용자 제안(이름만 미리 불러오기, 보이는 화 수 제한)은 이미 그렇게 되어 있음을 설명.

## 6단계: 자동 저장 (`187efdc`)
- **결정**: 입력 멈춤 1초 뒤 저장, 회차 전환·창 비활성·창 닫기·종료 때 즉시. 실패하면 본문을 메모리에 들고 빨간 표시, 그 상태로 종료하면 경고. 종료를 미루려고 `AppDelegate.swift`(AppKit 예외 2번째).
- **에러**: deinit에서 non-Sendable 속성 접근으로 빌드 실패 → `isolated deinit`.
- **결과**: 테스트 5개(조합 중 저장해도 조합 유지 포함).
