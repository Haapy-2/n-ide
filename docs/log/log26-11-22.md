## 안전 단계 1: 자동 저장 최대 대기 (해시는 다음 기록에)

- **이유**: 자동 저장이 "입력이 멈추고 1초 뒤"뿐이라, 쉬지 않고 계속 치면 저장이 계속 미뤄져 그동안 앱이 죽으면 그 글을 잃는다.
- **근거**: PLAN 17장 2번(사용자 채택). VS Code 백업 추적기도 입력마다 다시 예약하지만, 우리는 원본 파일이 곧 저장본이라 더 엄격히 둔다.
- **결과**: `EpisodeAutosaver`에 `maxWait`(기본 10초)과 `waitingSince`. 첫 변경부터 10초가 지나면 기다리지 않고 저장을 시작한다. 저장이 시작되거나 새 회차를 열면 시각을 지운다. NovelCore 131개·앱 185개(건너뜀 13) 통과.
- **에러**: perf.sh 앱 실행 중앙값 530.2ms(504.5~586.1ms)로 목표 500ms 미달. 이번 변경은 키 입력 뒤 저장 예약만 건드려 실행 경로와 무관하고, 같은 경계 문제는 17단계 과제로 이미 정해 둠. 키 입력 p95는 1.1ms로 그대로.
- **수정**: 새 테스트를 먼저 넣고 고치기 전 코드에서 실패하는 것을 확인한 뒤 고쳤다.
