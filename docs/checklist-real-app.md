# 실제 앱 확인 목록 (2026-11-26 고친 것)

자동 테스트로는 닿지 않는 부분(메뉴 흐림, 키보드 초점, 실제 입력기)을 실제 앱에서 확인한다.
Claude Code에서 이 파일을 열고 "docs/checklist-real-app.md 순서대로 verify-noveleditor 스킬로 확인해 줘"라고 하면 된다.
화면 제어 권한(컴퓨터 유스)을 허락해야 한다. 한글 조합 항목은 실제 키(`build/verify/keys`)라 잠시 화면을 빼앗는다.

## 준비

1. 사용자의 NovelEditor가 켜져 있으면 끈다(검증 앱과 설정 저장소가 같다).
2. `.claude/skills/verify-noveleditor/verify.sh launch` → 검증 작품(1·2·3화, 각 약 300자)이 열린 앱.
3. computer-use `request_access`에 `com.haapy2.NovelEditor`.
4. 끝나면 꼭 `verify.sh evidence <이름>` → `verify.sh cleanup`(설정 되돌리기, 검증 작품 지우기).

디스크 확인은 `grep -c <표시 문구> "build/verify/run/검증 작품.novel/episodes/"*.md`, 스냅샷은 `ls "build/verify/run/검증 작품.novel/snapshots/"*/`. 본문을 통째로 읽지 않는다.

## 확인할 것

| # | 해 볼 것 | 기대 결과 | 결과 |
|---|---|---|---|
| 1 | 본문 끝에 `qq VERIFY qq VERIFY qq` 입력 → 마지막 `qq` 뒤에서 ⇧← 한 번(`q` 하나 고름) → 편집 메뉴 `같은 말 하나 더 고르기` | 맞닿은 앞 `q`가 더 골라짐(두 자리) | |
| 2 | 1에 이어 ⌫ → 편집 메뉴 `실행 취소` | 두 `q`가 지워졌다가 ⌘Z 한 번에 둘 다 돌아옴. 한 번 더 ⌘Z가 엉뚱한 글자를 지우지 않음(디스크 `grep -c "qq VERIFY qq VERIFY qq"`가 1) | |
| 3 | 커서를 `VERIFY` 안에 두고 편집 메뉴 `같은 말 하나 더 고르기` 두 번(단어 고르기 → 하나 더) | 스냅샷 폴더에 `*-multicursor.md`가 하나 생김. 스냅샷 판(파일 › 스냅샷 보기…) 목록에 `여러 커서 전` | |
| 4 | 3에 이어 Esc, 같은 글로 다시 ⌘D 두 번 | `*-multicursor.md`가 더 생기지 않음(마지막과 같으면 건너뜀) | |
| 5 | 설정 › 편집기 `같은 말 여러 커서` 끄기 → 편집 메뉴 보기 | `같은 말 하나 더 고르기`가 흐림. ⌘D가 아무 일도 안 함. 설정 줄 아래 설명에 지금 단축키 `(⌘D)` | |
| 6 | 5에서 다시 켜고, 여러 커서 중에 설정에서 끄기 | 여러 커서가 끝나고 커서 하나 | |
| 7 | 편집기에 초점을 둔 채 편집 메뉴 `작품 전체 검색` → Esc → 곧바로 `ZZFOCUS` 입력 | 글이 편집기 본문에 들어감(디스크 `grep -c ZZFOCUS`가 1) | |
| 8 | 파일 › 스냅샷 보기…로 판을 연 채 메뉴 보기 | 회차 › `이름 변경…`, 편집 › `작품 전체 검색`·`전체 바꾸기 되돌리기…`가 흐림 | |
| 9 | 판을 연 채 다른 편집기(터미널 `printf`)로 2화 `.md` 끝에 ` OUTSIDE`를 붙이고 앱으로 돌아오기 → 판 닫기 | 판이 열린 동안 본문이 안 바뀌고, 판을 닫으면 바깥 글을 불러옴(앱 쪽 변경이 없을 때) | |
| 10 | 회차 하나만 남기고 휴지통 → 마지막 회차도 휴지통 → 사이드바에서 ⌘Z | 되살린 회차가 편집기에 열림(빈 종이가 아님) | |
| 11 | 회차를 묶음으로 묶고 접은 뒤, 사이드바에서 ↑↓ | 접힌 묶음 안 회차를 건너뜀. 묶음 안 회차가 열리는 길(검색 결과 등)로 가면 묶음이 펴지고 그 줄로 스크롤 | |
| 12 | 묶음 맨 앞 회차를 끌어 묶음 제목 줄 위에 놓기 / 바깥 회차를 제목 바로 아래에 놓기 | 앞은 묶음에서 빠지고, 뒤는 묶음의 첫 회원이 됨 | |
| 13 | 회차 3개를 ⌘클릭으로 골라 `3개 회차 이름 변경…` → 엔터를 빠르게 두 번 | 규칙이 한 번만 적용(예: 앞에 붙이기가 두 번 붙지 않음) | |
| 14 | 한글 체크리스트 23~28번(`docs/checklist-hangul.md`, 실제 키) | 각 항목의 기대 결과 | |

## 확인하지 못한 채 남은 것

- 충돌 창의 새 문구("…스냅샷으로 남기지 못해 바꾸지 않았어요")는 디스크를 일부러 막아야 해서 이 목록에 넣지 않았다. 자동 테스트(`ExternalChangeTests`)로만 확인했다.
- 단축키 막는 표의 전체 화면 ⌃⌘F 충돌은 실제 앱 보기 메뉴에 그 항목이 있는지부터 본다.
