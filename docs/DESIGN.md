# 디자인

방향은 **"잘 만든 종이 원고"**. 화면의 주인공은 글이고, 완성도는 장식이 아니라 타이포그래피·여백·정렬로 만든다.
사이드바·툴바·메뉴·설정 창은 시스템 표준 컨트롤과 재질을 쓰고, 개성은 편집 영역과 색, 글꼴에서만 낸다.
쓰지 않는 것: 둥근 카드, 그림자, 그라데이션, 강조색 여러 개, 아이콘 남발, 의미 없는 장식, 일러스트, 이모지, 시스템 컨트롤 흉내.

표시: **[SPEC]** = SPEC 5장에 있던 값, **[결정]** = SPEC에 없어서 이 문서에서 정한 값(승인 요청).

## 0. 리퀴드 글래스 [요청 2026-11-10]

Apple의 리퀴드 글래스(macOS 26부터 들어온 새 시스템 디자인)를 적용한다. 원칙은 Apple 지침 그대로, **유리는 콘텐츠 위에 뜨는 "조작 층"에만 쓰고, 글이 놓이는 콘텐츠 층(종이)은 불투명하게 둔다.** 그래서 "잘 만든 종이 원고" 방향과 충돌하지 않는다. 종이 위에 유리로 된 도구들이 떠 있는 모습이다.

| 자리 | 처리 |
|---|---|
| 사이드바 | `NavigationSplitView` 기본 사이드바. macOS 27에서는 창 안에 떠 있는 유리 패널로 자동 표시된다. 직접 재질을 칠하지 않는다. |
| 툴바와 툴바 버튼 | 시스템 툴바. 버튼은 시스템이 유리 묶음으로 자동 표시한다. |
| 설정 창, 시트, 팝오버, 메뉴 | 시스템 기본(자동으로 유리). |
| 편집 영역(종이) | **불투명 paper 색.** 글자 아래가 비치면 읽기 어렵고 입력 중 화면 갱신 비용도 늘어난다. 본문이 사이드바에 비치는 배경 확장 효과(`backgroundExtensionEffect`)는 쓰지 않는다. 대신 창 바탕을 반투명 재질(`containerBackground(.ultraThinMaterial, for: .window)`)로 해서 **사이드바 뒤로 다른 앱과 바탕화면이 흐릿하게 비친다**. 기본은 켬이고 설정 창(10단계)의 "사이드바 뒤로 창 비치기"로 끈다(2026-11-10 사용자 요청). |
| 상태 줄 | 유리 없이 종이 위 글자. 타이핑 중 사라지는 요소라 유리 판을 얹으면 오히려 눈에 띈다. |
| 직접 만드는 유리(`glassEffect`) | 1차 버전에서는 쓰지 않는다. 필요해지면(예: 집중 모드에서 잠깐 나타나는 조작 버튼) 그 단계에서 제안하고 여기에 기록한다. |
| 유리 색 입히기(tint) | 하지 않는다. 강조색은 하나뿐이라는 원칙 때문에 유리는 시스템 기본 그대로 둔다. |

- 시스템 컨트롤만 쓰면 유리가 자동으로 적용되므로, 유리를 흉내 낸 반투명 배경이나 흐림 효과를 직접 만들지 않는다.
- 시스템 설정의 "투명도 줄이기", "대비 증가"가 켜지면 시스템이 유리를 불투명하게 바꾼다. 앱에서 따로 막지 않는다.
- `sidebar` 색 토큰은 유리를 쓸 수 없을 때(투명도 줄이기 등)의 기준값으로만 남는다.
- 사이드바 위의 글자 대비는 유리 뒤 배경(종이색)에 따라 달라진다. 1단계 스냅샷에서 inkMuted가 흐려 보이면 시스템 보조 글자 색으로 바꾸고 여기에 기록한다.

## 2. 글꼴

| 용도 | 글꼴 | 비고 |
|---|---|---|
| 본문 기본 | Pretendard Regular | [SPEC] OFL. 공식 저장소에서 받아 `App/Resources/Fonts/`에 라이선스 파일과 함께 번들 |
| 본문 선택지 | Pretendard / Apple SD 산돌고딕 Neo / AppleMyungjo | [SPEC] 설정 창에서 고른다 |
| UI 전체 | 시스템 글꼴 | [SPEC] 본문 글꼴과 섞지 않는다 |
| 숫자 | 시스템 글꼴의 고정폭 숫자 | [SPEC] 글자 수가 바뀌어도 폭이 흔들리지 않게 |

- 번들 범위 **[결정]**: Pretendard는 Regular 한 굵기만 넣는다. 서식(굵게 등)을 만들지 않으므로 다른 굵기는 쓸 곳이 없고, 앱 용량과 실행 시간을 줄인다.
- UI 글자 크기 **[결정]**: 사이드바 회차 제목 13pt, 사이드바 번호와 글자 수 11pt, 상태 줄 11pt, 빈 화면 안내 13pt. 모두 시스템 글꼴.

## 3. 편집 영역

| 항목 | 기본값 | 설정 범위 | |
|---|---|---|---|
| 글자 크기 | 17pt | 13~24pt (1pt 단위) | [SPEC] |
| 줄 간격 | 1.75배 | 1.4~2.2배 (0.05 단위) | [SPEC] |
| 문단 간격 | 0.6줄 | 0~1.5줄 (0.1 단위) | [SPEC] |
| 본문 폭 | 한 줄 약 40자 | 30~55자 (1자 단위) | [SPEC] |

정한 것 **[결정]**:

- **본문 폭 계산**: 한글 한 글자의 폭을 글자 크기(1em)로 보고 `글자 수 × 글자 크기`로 정한다. 기본값이면 40 × 17 = 680pt. 창이 이보다 좁으면 창에 맞춰 줄고, 넓으면 본문을 가운데 두고 나머지는 여백.
- **줄 높이**: 줄 높이를 `글자 크기 × 줄 간격`으로 고정한다(최소·최대 줄 높이를 같게). 글꼴마다 기본 줄 높이가 달라도 줄 간격이 흔들리지 않게 하려는 것이다.
- **문단 간격**: 문단(줄바꿈) 뒤에 `줄 높이 × 0.6`. 들여쓰기는 하지 않는다. 웹소설은 빈 줄과 문단 간격으로 문단을 나누는 것이 일반적이라서.
- **위 여백**: 36pt(처음 72pt, 2026-11-12 사용자 요청으로 반).
- **아래 여백**: 보이는 영역 높이의 절반. 마지막 줄을 화면 가운데 근처까지 끌어올려 쓸 수 있게.
- **커서**: accent 색, 시스템 기본 굵기.
- **스크롤 막대**: 시스템 기본(스크롤할 때만 나타나는 오버레이 방식).
- **창 크기**: 처음 1100 × 760pt, 최소 720 × 480pt.

### 사이드바

- SwiftUI `NavigationSplitView`의 시스템 사이드바(떠 있는 유리 패널)를 그대로 쓴다. 폭 기본 240pt, 최소 200pt, 최대 340pt.
- 맨 위에 작품 제목(13pt, 굵게는 시스템 헤더 스타일). 아래에 "회차" 구역, 그 아래 접을 수 있는 "노트" 구역(PLAN 결정 사항 4).
- 회차 한 줄: `번호  제목  글자 수`. 번호는 **왼쪽 정렬** 고정폭 숫자로, "회차" 제목 글자와 같은 선에서 시작한다(제목도 모두 한 선, 2026-11-12 사용자 요청). 이 선은 **창의 빨간 닫기 버튼 왼쪽 끝**에 맞춘다. 값은 박아 두지 않고 실행 중에 잰다(창 크기·사이드바 접기·화면 이동 때 다시 잼, 버튼이 안 보이는 전체 화면에서는 8pt). 회색 선택 칸은 줄 끝까지. 글자 수는 오른쪽 끝에 inkMuted 11pt, 천 단위 쉼표, 설정에서 숨길 수 있다. 제목이 길면 끝을 말줄임.
- 선택 표시: **직접 그린 은은한 회색 배경 하나**(ink 8%, 둥근 모서리 6pt). 시스템 선택 모양은 누르는 순간 파랗게 칠했다가 편집기로 초점이 넘어가면 회색이 되어 번쩍이고, 이를 끌 방법이 없어 쓰지 않는다(사용자 요청). 사이드바는 회차를 클릭하면 키보드 초점을 받아 ↑↓로 회차를 옮길 수 있다(초점 테두리는 그리지 않음). 편집기에서는 ⌥⌘↑/↓.
- 아이콘: 사이드바 안에는 넣지 않는다.

### 툴바

- 시스템 툴바(버튼은 유리 묶음으로 자동 표시). 제목 자리에 `작품 제목 — 회차 제목`.
- 제목은 **편집 영역(종이) 쪽 툴바 왼쪽에 고정**한다. 사이드바 쪽에 두면 사이드바 폭만큼만 보여서 긴 제목이 잘린다. 한 줄로만 쓰고, 창이 아주 좁을 때만 끝이 `…`로 줄어든다.
- 버튼은 세 개만: 사이드바 토글(시스템), 새 회차, 노트 분할. 나머지 기능은 메뉴와 단축키로.
- 집중 모드에서는 툴바도 숨긴다.

### 상태 줄

- 편집 영역 맨 아래 한 줄, 높이 28pt, 좌우 끝을 본문 폭에 맞춘다. 배경 없음(종이 위에 바로 글자).
- 왼쪽: 글자 수 (inkMuted 11pt, 고정폭 숫자). 설정의 표시 방식에 따라 `1,204자 · 공백 제외 987자`(둘 다, 기본), `1,204자`(공백 포함만), `공백 제외 987자`(공백 제외만).
- 진행률은 설정의 목표 기준(공백 포함, 기본 / 공백 제외)으로 계산한다.
- 가운데 오른쪽: 목표 진행률 `24%`와 그 옆 모양(accent). 화면에서 accent가 나오는 두 번째이자 마지막 자리. 모양은 설정 "진행률 모양"(2026-11-12 사용자 요청):
  - **원**(기본): 지름 14pt, 선 2pt 고리. 12시에서 시계 방향으로 채우고 끝은 각지게(둥글면 조금 남은 틈이 덮임).
  - **막대**: 숫자 옆 한 줄, 폭 80pt, 높이 4pt, 양 끝 둥글게.
  - 남은 부분 트랙은 inkMuted 35%(rule 색은 다크 모드에서 종이와 거의 같아 안 보였음). 100%를 넘으면 숫자만 올라가고 모양은 가득. 마우스를 올리면 "목표 5,000자 · 150자 남음".
- 오른쪽 끝: 저장 상태. 평소에는 비어 있음. 저장 중이면 `저장 중…`(inkMuted), 실패하면 `저장 실패 · 다시 시도 중`(error), 재시도까지 실패하면 `저장 실패 · 원고는 메모리에 있음`(error)과 클릭하면 자세한 이유를 보여준다.
- 상태 줄은 본문 위 아래쪽에 겹쳐 뜬다. 보일 때는 종이색 바탕으로 아래 글을 가리고, 숨으면 바탕도 사라져 본문이 창 맨 아래까지 보인다(저장 실패 표시가 있으면 바탕 유지).
- 진행률 모양: 원(고리, 기본) / 원(꽉 찬, 12시부터 시계 방향 부채꼴) / 막대.
- 숨기기(2026-11-12 사용자 요청으로 바뀜, 설정 창 "화면" 묶음): 타이핑 중에는 **기본 계속 보인다**("숨기기"를 고르면 치기 시작하고 1초 뒤 사라지고 입력이 1.5초 멈추면 나타남). 쉬고 있을 때는 **기본 마지막 입력·마우스 움직임 10초 뒤 사라진다**("계속 보이기"를 고를 수 있음). 마우스를 움직이면 나타난다. 저장 실패 표시는 숨지 않는다.
  - SPEC 충돌 메모: SPEC 5장은 "타이핑을 시작하면 서서히 흐려진다"이다. 사용자 요청(치는 동안 글자 수를 보고 싶음)을 따르고, SPEC 방식은 설정으로 남긴다.
  - SPEC 충돌 메모: SPEC은 상태 줄이 "서서히" 흐려진다고 하면서 애니메이션은 150ms 이내라고 한다. 애니메이션 규칙을 우선해 **150ms** 페이드로 한다. "서서히"의 느낌은 바로 사라지지 않고 1초 기다리는 것으로 낸다.

### 작품 선택 창 (Obsidian 볼트 선택처럼)

앱을 열면 작업 공간보다 먼저 뜨는 작은 창. 작품을 고르면 이 창은 닫히고 작업 공간 창이 열린다.

```
┌──────────────────────────────────────────────┐
│ ● ● ●                                        │
│                                              │
│   NovelEditor                                │
│                                              │
│   최근 작품                                  │
│   ┌──────────────────────────────────────┐   │
│   │ 달빛 아래 검        212화 · 어제      │   │
│   │ ~/Documents/달빛 아래 검.novel        │   │
│   │ 시험용 단편           3화 · 11월 2일  │   │
│   │ ~/Desktop/시험용 단편.novel           │   │
│   └──────────────────────────────────────┘   │
│                                              │
│   [새 작품…]   [다른 위치에서 열기…]         │
└──────────────────────────────────────────────┘
```

- 크기 고정 560 × 420pt. 창 배경은 시스템 기본(유리 창 배경), 목록은 시스템 `List`.
- 목록 한 줄: 작품 제목(13pt) + 오른쪽에 `212화 · 어제`(inkMuted 11pt), 아래 줄에 폴더 경로(inkMuted 11pt, 가운데 말줄임). 최근에 연 순서.
- 선택 표시는 작업 공간 사이드바와 같은 직접 그린 회색 칸(ink 8%, 둥근 모서리 6pt). 시스템 파란 선택은 쓰지 않는다(사용자 요청).
- 두 번 클릭 또는 ↩로 열기. 오른쪽 클릭 메뉴: "Finder에서 보기", "목록에서 빼기"(폴더는 그대로).
- 아래에 시스템 버튼 두 개: `새 작품…`(기본 버튼), `다른 위치에서 열기…`.
- 경로가 없어진 작품(Finder에서 옮김·삭제)은 선택 창을 열 때 목록에서 조용히 뺀다. 원고는 건드리지 않는다(PLAN 결정 사항 8).
- 최근 작품이 하나도 없으면 목록 대신 `아직 작품이 없어요. 새 작품을 만들어 주세요.` 한 줄.
- 작업 공간에서 메뉴 "작품 전환…"(⇧⌘O)을 고르면 이 창으로 돌아온다.

### 빈 화면

- 작품이 없을 때: 작품 선택 창이 대신한다(위).
- 회차가 없을 때: `첫 회차를 추가해 주세요.`와 버튼 `새 회차` 하나.
- 일러스트·아이콘·이모지 없음.

### 설정 창

- SwiftUI `Settings` 장면, 시스템 기본 폼 스타일. 탭 없이 한 화면에 두 묶음.
- **편집기** 묶음: 미리보기 문장 두 줄(실제 본문 설정으로 종이색 위에 표시), 본문 글꼴(팝업 메뉴), 글자 크기·줄 간격·문단 간격·본문 폭(각각 슬라이더 + 숫자 표시).
- **글자 수** 묶음: 표시 방식(공백 포함 / 공백 제외 / 둘 다, 기본 둘 다), 목표 기준(공백 포함 / 공백 제외, 기본 공백 포함), 진행률 모양(원 / 막대, 기본 원)은 시스템 팝업 메뉴. 글자 수 갱신(실시간 / 0.1 / 0.2 / 0.3초, 기본 0.2초)은 슬라이더.
- **글자 수** 묶음에 "사이드바에 글자 수 보이기"(기본 켬).
- **화면** 묶음: 테마(다크 / 기기 설정 / 라이트 아이콘 세그먼트, 기본 기기 설정), 타이핑 중 상태 줄(계속 보이기 / 숨기기), 쉬고 있을 때 상태 줄(계속 보이기 / 10초 뒤 숨기기), "사이드바 뒤로 창 비치기"(기본 켬).
- 값이 바뀌면 열려 있는 편집 영역에 바로 반영된다.
- **되돌리기** 묶음: 확인 창 다시 띄우기(하루 뒤 / 3일 뒤 / 일주일 뒤(기본) / 한 달 뒤 / 띄우지 않기), 쉬는 중일 때만 "지금부터 다시 묻기" 버튼.
- 사이드바 ⌘Z·⇧⌘Z 확인 창: 제목 `"이름 변경"을 되돌릴까요?`, 내용 `회차 목록이 바뀌기 전으로 돌아가요. 본문은 바뀌지 않아요.`, 체크 `다시 묻지 않기`, 버튼 `취소`(엔터·Esc) / `되돌리기`. 편집기의 ⌘Z·⇧⌘Z는 묻지 않는다.
- 작품별 값(새 회차 기본 목표)은 설정 창에 넣지 않는다. 설정 창은 어느 작품 창에도 속하지 않아서다. 대신 회차 메뉴 "목표 글자 수…" 창의 버튼 `이 회차만` / `새 회차에도 쓰기`로 고른다(2026-11-12 사용자 요청: 메뉴를 늘리지 않기).

### 나중 단계 화면 (해당 단계에서 다시 확정)

- **검색·바꾸기**(12·13단계): 사이드바 자리를 검색 패널로 바꿔 보여준다(Xcode의 찾기 탐색기처럼). 위에 입력 칸, 아래에 회차별로 묶인 결과(일치 부분만 accent 18% 배경).
- **스냅샷**(11단계): 시트 하나. 왼쪽에 시각 목록(수동은 "직접" 표시), 오른쪽에 내용 미리보기, 아래에 `복원` 버튼.
- **노트 분할**(15단계): 편집 영역 오른쪽에 노트 편집 영역, 사이에 rule 색 1pt 구분선. 노트 영역 최소 폭 260pt, 노트 글자는 본문보다 2pt 작게.
- **집중 모드**(14단계): 사이드바, 툴바, 상태 줄을 숨긴다. 전체 화면으로 바꾸지는 않는다(원하면 시스템 전체 화면을 따로 쓰면 된다).

|---|---|
| 사이드바 토글 | 시스템 제공 |
| 새 회차 | `square.and.pencil` |
| 노트 분할 | `sidebar.right` |

앱 아이콘은 17단계에서(PLAN 결정 사항 5).

## 6. 움직임 [SPEC]

- 애니메이션은 상태 변화를 알릴 때만, 150ms 이내.
- 타이핑 중에는 어떤 애니메이션도 입력을 늦추지 않는다(상태 줄 페이드는 입력 처리와 분리).
- 시스템 "동작 줄이기"가 켜져 있으면 애니메이션 없이 즉시 바뀐다.

## 7. 메뉴와 단축키 [결정]

시스템 표준 단축키(복사, 붙여넣기, 실행 취소, ⌘,, ⌃⌘S 사이드바 등)는 그대로 둔다.

| 메뉴 | 항목 | 단축키 |
|---|---|---|
| 파일 | 새 작품… | ⇧⌘N |
| 파일 | 다른 위치에서 열기… | ⌘O |
| 파일 | 작품 전환… (작품 선택 창으로) | ⇧⌘O |
| 파일 | 지금 저장 | ⌘S |
| 파일 | 스냅샷 찍기 | ⌥⌘S |
| 파일 | 스냅샷 보기… | ⇧⌘S |
| 파일 | 내보내기… | ⇧⌘E |
| 편집 | 작품 전체 검색 | ⇧⌘F |
| 편집 | 작품 전체 바꾸기 | ⌥⌘F |
| 회차 | 새 회차 | ⌘N |
| 회차 | 이전 회차 / 다음 회차 | ⌥⌘↑ / ⌥⌘↓ |
| 회차 | 이름 변경… | ⇧⌘R, 사이드바에서 ↩ 또는 두 번 클릭 |

| 회차 | 목표 글자 수… | 없음 |
| 보기 | 집중 모드 | ⇧⌘↩ |
| 보기 | 타자기 스크롤 | ⌥⌘T |
| 보기 | 노트 나란히 보기 | ⌥⌘N |

## 8. 디자인 확인

- 화면이 바뀌는 단계마다 라이트/다크 스냅샷을 `docs/design-snapshots/`에 저장한다. 파일 이름은 `<단계번호>-<화면>-<light|dark>.png` (예: `05-long-text-dark.png`).
- 포함할 화면: 빈 화면, 회차가 많은 화면(500회차), 긴 본문 화면, 그리고 그 단계에서 새로 생긴 화면.
- 만드는 법: `Scripts/snapshots.sh`. 한계: 창을 화면 밖에서 그려 뜨기 때문에 리퀴드 글래스(사이드바 유리 등)는 하얗게 찍힌다. 유리 부분은 실제 앱에서 확인한다.
