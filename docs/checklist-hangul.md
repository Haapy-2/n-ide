# 한글 입력 손 확인 체크리스트

자동 테스트로 잡기 어려운 부분이라 손으로 확인한다. 편집기에 영향을 주는 단계(편집기, 자동 저장, 글자 수, 타자기 스크롤 등)가 끝날 때마다 다시 본다.
준비: `Scripts/run.sh` → 작품 열기 → 회차 하나 선택 → macOS 기본 한글 입력기(두벌식).

각 항목에서 확인할 것: **글자가 빠지거나 겹치지 않는다, 자모가 풀리지 않는다(예: "ㅎㅏㄴ"), 커서가 엉뚱한 곳으로 튀지 않는다.**

| # | 해 볼 것 | 기대 결과 | 5단계 |
|---|---|---|---|
| 1 | "안녕하세요 반갑습니다"를 평소 속도로 친다 | 그대로 입력됨 | |
| 2 | "ㅋㅋㅋㅋ", "읽었다", "값어치"를 아주 빠르게 연타한다 | 겹받침·연타에서 글자 빠짐 없음 | |
| 3 | "한"을 조합하던 중(ㅎㅏ 상태)에 ← → ↑ ↓ 방향키 | 조합 중이던 글자가 확정되고 커서만 움직임 | |
| 4 | 조합 중에 마우스로 다른 위치 클릭 | 조합 글자 확정, 클릭한 곳으로 커서 이동 | |
| 5 | 조합 중에 사이드바에서 다른 회차 클릭 | 앱이 멈추거나 글자가 다른 회차로 넘어가지 않음 | |
| 6 | 조합 중에 ⌘Z, ⌘A, ⌘C | 이상한 글자가 남지 않음. ⌘Z는 조합 글자를 확정한 뒤 되돌린다(2026-11-12) | |
| 7 | 긴 문단 중간에 커서를 두고 한글 입력 | 뒤쪽 글자가 밀릴 뿐 깨지지 않음 | |
| 8 | 줄 끝에서 입력해 줄이 넘어갈 때 | 조합 중 글자가 다음 줄로 잘 넘어감 | |
| 9 | 한/영 전환(Caps Lock 또는 ⌃Space)을 섞어 입력 | 영문·한글 모두 정상 | |
| 10 | 따옴표 "대사"와 말줄임표… 입력 | 자동으로 다른 문자로 바뀌지 않음 | |
| 11 | 입력을 멈추고 1~2초 기다렸다 계속 (자동 저장 시점, 6단계부터) | 조합이 끊기지 않음 | 6단계부터 |
| 12 | 글자 수가 바뀌는 동안 계속 입력 (9단계부터) | 조합이 끊기지 않음 | 9단계부터 |
| 13 | 타자기 스크롤을 켜고 입력 (14단계부터) | 조합이 끊기지 않음 | 14단계부터 |
| 14 | "한"을 조합하던 중에 ⌘,로 설정 창을 열어 글자 크기·글꼴을 바꾸고 편집기로 돌아와 계속 입력 (10단계부터) | 조합하던 글자가 확정되거나 그대로 이어지고, 글자가 빠지거나 겹치지 않음. 본문 전체가 새 모양으로 바뀜 | 10단계부터 |

5단계 칸에 ✓ 또는 문제 내용을 적는다.
