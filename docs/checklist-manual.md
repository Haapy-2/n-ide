# 사용자 손 확인 목록

실제 앱에서 사용자가 직접 해 볼 것. 끝난 묶음은 지우고 작업 기록에 "손 확인 끝"으로 남긴다. 지금 상태는 [PROGRESS.md](PROGRESS.md).


## 14-1 ③b 그림 넣기 손 확인
1. `Scripts/run.sh`로 작품을 열고 Finder에서 그림(PNG·JPEG·GIF 아무거나)을 본문 가운데로 끌어 놓는다. 놓은 자리에 그림이 들어가고, 줄 가운데였으면 그 줄이 둘로 나뉜다(자동 확인에서 끌기가 시작되지 않아 사람이 본다).
2. 편집 → `그림 넣기…`로 그림 두 장을 함께 고른다. 두 장이 한 줄씩 들어가고 ⌘Z 한 번에 둘 다 빠진다.
3. 스크린숏을 클립보드로 찍고(⌃⇧⌘4) 본문에 ⌘V → 그림으로 들어간다. 글을 복사해 ⌘V 하면 글로 들어간다.
4. 한글 체크리스트: "하"를 조합하던 중에 그림을 끌어 놓아도 조합 글자가 깨지지 않고 그림은 그 뒤에 들어간다.
5. Finder에서 `images/` 속 그림 하나를 휴지통으로 옮긴 뒤 앱 창을 클릭 → 회색 상자. 상자를 오른쪽 클릭 → `다른 그림으로 바꾸기…`로 다른 그림을 고르면 바뀌고, ⌘Z로 상자로 돌아간다.

## 회차 묶음 손 확인
1. 1화를 누르고 3화를 ⌘클릭 → 두 줄 모두 회색. 우클릭 `2개 회차 묶기…` → 이름 입력 → 3화가 1화 바로 아래로 오고 묶음 제목 줄이 생기는지. ⌘Z(사이드바에 초점) → 원래대로.
2. ⇧클릭으로 범위 고르기, 우클릭 `묶음에 넣기 ▸`.
3. 묶음 밖 회차를 묶음 한가운데로 끌어 놓으면 들어가고, 묶음 회차를 밖으로 끌면 빠지는지.
4. 묶음 제목 두 번 클릭 → 이름 변경. 우클릭 `묶음 풀기`. 접고 앱을 껐다 켜도 접혀 있는지.

## 12단계 손 확인
1. ⇧⌘F → 사이드바가 검색 패널로 바뀌고 입력 칸에 커서. **한글을 조합하면서 쳐도 입력 칸 글자가 깨지지 않는지**(치는 중에 결과가 바뀜).
2. 결과를 누르면 그 회차로 가서 문구가 노랗게 표시되고 바로 이어 쓸 수 있는지. 같은 회차 안의 다른 결과도.
3. 본문에 새 문구를 치고 1초 안에 검색 → 방금 친 것도 찾히는지.
4. `Aa`를 켜고 영어 대소문자가 구분되는지. Esc·✕로 회차 목록에 돌아오고, 다시 ⇧⌘F 하면 문구와 결과가 남아 있는지.

## 11g 손 확인
11d·11e·11f 손 확인(아래 각 항목)과 한글 체크리스트 15번. 11d "줄 전체" 기준은 0.6으로 정함(PLAN 6장 24번).

## 점검 손 확인
1. 설정 › 단축키에서 칸을 눌러 기록 상태로 두고 원고 창으로 가서 ⌘S → 저장되고 기록은 취소되는지.
2. 한글 체크리스트에서 조합 중 회차 전환(⌥⌘↓) → 앞 회차의 자모가 새 회차에 안 들어가는지.

## 커서 설정 손 확인
1. 두께에 7, 0.3, 2.3을 넣고 엔터 → 4, 1, 2.5로 바뀌고 편집기 커서도 바로 바뀌는지.
2. 라이트·다크에 서로 다른 색을 고르고 앱 테마를 바꿔 커서 색이 따라 바뀌는지. 컬러 피커로 고른 색도.
3. `기본값으로` → 2pt·1.2배·두 모드 모두 기본 파랑으로 돌아오는지.
4. 굵게(4pt) 한 뒤 커서를 옮겨도 자국이 안 남는지.

## 커서 손 확인
1. 글자 크기를 13·17·24pt로 바꿔 가며 커서가 글자보다 살짝 크고 가운데에 있는지.
2. 화살표·클릭으로 여기저기 옮기고, 한글을 치고 지워도 옛 자리에 파란 자국이 안 남는지.

## 11f 손 확인
1. ⌘, → 편집기 → "줄 번호 보이기"를 켠다 → 본문 글자가 한 칸도 안 움직이고 왼쪽 여백 끝에 회색 번호가 생긴다. 끄면 사라진다.
2. 긴 문단은 첫 줄에만 번호, 빈 줄에도 번호. 맨 끝에서 엔터를 치면 새 빈 줄에 바로 번호가 붙는다.
3. 중간에서 엔터를 치거나 줄을 지우면 아래 번호가 모두 따라 바뀌고 옛 번호가 남지 않는다. 스크롤해도 번호가 맞다.
4. 창을 좁히면 번호만 사라지고 본문은 그대로.
5. **창이 넓을 때 번호와 문단을 눈으로 잇기 괜찮은지**(A안의 약점) 봐 주세요. 불편하면 거리 값(20pt)만 바꾸면 된다.
6. 한글 체크리스트 15번.
7. ⇧⌘S 비교 화면의 줄 번호와 편집기 번호가 같은 문단을 가리킨다.

## 오른쪽 여백 클릭 손 확인
1. 짧은 줄(예: "여기서 뭐 해요?")의 오른쪽, 본문 칸 바깥 여백을 누른다 → 커서가 그 줄 끝에 온다.
2. 긴 줄의 오른쪽 여백을 누른다 → 그 줄 끝(다음 줄 맨 앞이 아니라)에 온다. 끌어서 선택도 오른쪽 여백에서 시작된다.

## 토스트 손 확인
1. 작품을 열고 몇 글자 친 뒤 ⌘S → 오른쪽 위 툴바 바로 아래에 `✓ 저장했어요`가 유리 바탕으로 뜨고 2초(기본) 뒤 사라진다. 커서는 그대로, 바로 이어 쓸 수 있다. **유리 모양과 자리가 괜찮은지** 봐 주세요(디자인 스냅샷에는 유리가 안 찍힘).
2. 창 폭을 줄이거나 사이드바를 접어도 오른쪽 위에 붙어 있다.
3. ⌃⌘S → `스냅샷을 찍었어요 · 메모 달기`. 그냥 두면 사라지고 메모 창은 안 뜬다. 다시 찍고 `메모 달기`를 누르면 "스냅샷 메모" 창이 뜬다.
4. 토스트 위에 마우스를 올려 두면 사라지지 않고, 내리면 설정한 시간 뒤 사라진다.
5. ⌘, → 일반 → 알림 → 유지 시간을 5초로 → ⌘S → 5초 머문다.
6. ⌘, → 단축키 → "저장하면서 스냅샷 찍기" 스위치를 켠다 → 지금 저장·스냅샷 찍기 칸이 흐려지고 눌러도 녹화되지 않는다. 새 줄 칸은 녹화된다. 작품 창에서 글을 고치고 ⌘S → `스냅샷 저장됨 · 메모 달기`. 고치지 않고 다시 ⌘S → `저장했어요`. ⇧⌘S 판에 스냅샷이 하나만 늘었다. 스위치를 끄면 원래대로. 한글 조합 중("하")에 ⌘S를 눌러도 글자가 깨지지 않는다.

## 11e 손 확인
1. 글을 조금 고치고 ⇧⌘S → 오래된 스냅샷을 골라 `이 버전으로 되돌리기` → 판이 닫히고 본문이 옛 글, 커서가 편집기에 있고 바로 이어 쓸 수 있다. 상태 줄에 `시:분:초 버전으로 되돌렸어요 · 취소`.
2. `취소`(또는 ⌘Z 한 번) → 되돌리기 전 글. 다시 ⇧⌘Z → 옛 글.
3. 다시 ⇧⌘S → 목록 맨 위에 `복원 전`, 메모 "…버전으로 되돌림". 그걸 골라 되돌리면 되돌리기 전 글로 돌아가고 `복원 전`이 하나 더 생긴다.
4. 맨 위(지금과 같은 것)를 고르면 버튼이 흐리고, 마우스를 올리면 "지금 글과 같아요".
5. 되돌린 뒤 2초 기다려 앱을 끄고 다시 열면 되돌린 글이 남아 있다.

## 단축키 손 확인
1. ⌘, → 단축키: 세 묶음이 보인다. "지금 저장" 칸을 누르고 ⌃⌘J → 칸이 ⌃⌘J로 바뀌고 "기본값" 버튼이 생긴다. 파일 메뉴의 지금 저장 옆도 ⌃⌘J. 작품 창에서 ⌃⌘J가 저장한다.
2. **한글 입력 상태에서** 칸을 누르고 ⌃⌘S → "⌃⌘S"로 기록된다("ㄴ"이 아님). 앱 명령끼리 겹친다는 물음이 뜨면 취소.
3. ⌘Q를 누르면 "앱 종료에 쓰여서 고를 수 없어요", J만 누르면 "⌘를 함께 눌러 주세요".
4. 스냅샷 찍기 칸에 ⇧⌘S → "‘스냅샷 보기…’이(가) 쓰고 있어요" → 바꾸기 → 스냅샷 보기는 "없음".
5. 칸을 누른 채 Esc → 그대로, ⌫ → "없음". "모두 기본값으로"로 원래대로. 앱을 껐다 켜도 바꾼 값이 남는다.
6. 사이드바에 초점이 있을 때 ⌘⌫로 휴지통(기본값일 때만), 편집기에서는 ⌥⌘⌫.

## 11d 손 확인
1. `Scripts/run.sh` → 작품을 열고 몇 글자 고친 뒤 ⌃⌘S로 스냅샷(메모 "테스트"). 한 문단을 조금(조사 하나), 다른 문단을 많이 고친다.
2. ⇧⌘S → 판이 뜨고 뒤가 어두워진다. 왼쪽 맨 위 `직접`과 메모 "테스트"가 보이고 오른쪽에 바로 비교가 나온다. 조금 고친 문단은 그 글자만, 많이 고친 문단은 줄 전체가 칠해진다. 기준은 0.6으로 정했어요(PLAN 6장 24번). 실제 원고에서 어색하면 알려 주세요.
3. 과거 칸 글자를 끌어 골라 ⌘C → 판을 닫고 편집기에 붙여 넣기.
4. 목록 줄을 두 번 클릭 → 메모를 고치고 엔터. 비우고 엔터면 메모가 사라진다. 고치는 중 Esc는 고치기만 그만둔다.
5. Esc, ✕, 판 바깥(사이드바·편집기 자리) 누르기 각각으로 닫힌다. 닫으면 커서가 원래 자리에 있고 바로 이어 쓸 수 있다. 한글 조합 중("하")에 ⇧⌘S를 눌러도 글자가 깨지지 않는다.
6. 긴 회차에서 같은 줄이 많으면 `같은 줄 N개`로 접히고 누르면 펼쳐진다.

## 세 번째 점검 손 확인
1. 회차 하나에 몇 글자 쓰고 2초 기다린 뒤 휴지통으로 보내기 → 사이드바에서 ⌘Z(확인 창에서 되돌리기) → 되살아난 회차에 한 줄 더 쓰고 2초 뒤 앱을 끄고 다시 연다 → 마지막 줄이 남아 있다.
2. 글을 쓰다 멈췄을 때 끊김이 없는지(저장이 1회 3ms쯤 길어졌지만 메인 스레드 밖).

## 앞 점검 손 확인
1. 글을 치는 동안 사이드바에서 지금 회차의 글자 수가 따라 바뀐다. 다른 회차로 갔다 와도 숫자가 남아 있다(글자 수 저장 방식을 바꿈).
2. 작품을 연 채 파일 → 작품 전환… → 같은 작품을 최근 목록에서 다시 열면 새 창이 생기지 않고 열려 있던 창이 앞으로 온다.
3. 회차 이름을 바꾸고 바로 ⌘Q → 다시 열면 바뀐 이름이 남아 있다.

## 11단계 손 확인 (11a·11b)
1. `Scripts/run.sh` → 작품을 열고 1화에 몇 글자 친 뒤 2화로 간다. Finder에서 작품 → 패키지 내용 보기 → `snapshots/<1화 ID>/`에 `<시각>-leave.md`가 생긴다. 아무것도 안 고치고 오가면 새 파일이 안 생긴다.
2. ⌃⌘S → "스냅샷을 찍었어요" 창. 메모를 쓰고 엔터 → 같은 이름의 `-manual.md`와 `-manual.memo`. 비워 두고 엔터나 `메모 없이`면 `.memo`가 없다. 한글 조합 중에 ⌃⌘S를 눌러도 글자가 깨지지 않는다.
3. ⌘, → 일반 → 스냅샷: 자동 끄면 간격이 흐려진다. 간격 5분으로 두고 글을 고친 채 5분 기다리면 `-auto.md`. 보관 개수를 10으로 두고 여러 번 찍으면 auto·leave가 10개만 남고 manual은 남는다.
4. 글을 고친 채 ⌘Q → 다시 열면 그 회차에 `-leave.md`가 있다.
5. 8단계 손 확인 3번(충돌 때 `-conflict.md`, `-external.md`)을 한 번 더(코드 경로가 바뀜).

5. 편집기에서 몇 글자 치고 ⌘Z → 지워짐, ⇧⌘Z → 다시 생김. 한글 조합 중 ⌘Z도 깨지지 않는다.
6. 사이드바에서 회차 이름을 바꾼 뒤 사이드바를 클릭하고 ⌘Z → 확인 창. 엔터 → 취소. 다시 ⌘Z → "다시 묻지 않기" 체크 → 되돌리기 → 다음 ⌘Z는 묻지 않는다. 설정 "되돌리기"에 "…까지 묻지 않음 / 지금부터 다시 묻기"가 보인다.

## 10단계 손 확인
1. `Scripts/run.sh` → 작품을 열고 ⌘,로 설정 창을 연다. 미리보기 두 줄이 보인다.
2. 글꼴(Pretendard / Apple SD 산돌고딕 Neo / AppleMyungjo), 글자 크기, 줄 간격, 문단 간격, 본문 폭을 바꾼다. 미리보기와 열려 있는 편집 영역이 바로 바뀌고, 상태 줄 좌우 끝이 본문 폭을 따라간다. 슬라이더를 끌 때 끊기지 않는다.
3. 글자 수 표시·목표 기준·진행률 모양(원/막대)·사이드바 뒤로 창 비치기를 바꾸면 상태 줄·사이드바가 바로 바뀐다.
4. 앱을 끄고 다시 켜서 바꾼 값이 남아 있는지 본다.
5. 회차 메뉴 → "목표 글자 수…" → 3000 → `새 회차에도 쓰기`. 새 회차(⌘N)의 진행률이 3,000자 기준이다. `이 회차만`은 그 회차만 바뀐다.
6. 한글 체크리스트 14번: "한"을 조합하던 중에 ⌘,로 글자 크기를 바꾸고 돌아와 계속 쓴다.

## 9단계 손 확인
1. `Scripts/run.sh` → `build/perf/더미 500화.novel`(perf.sh가 만든 더미, 없으면 `Scripts/perf.sh` 한 번)을 연다. 사이드바 회차마다 오른쪽 끝에 글자 수(1~10화 5,000, 나머지 300)가 보인다.

## 8단계 손 확인
1. `Scripts/run.sh`로 작품을 열고 아무 회차나 연다. Finder에서 작품(.novel) 우클릭 → 패키지 내용 보기 → `episodes/`에서 그 회차 파일(`project.json`에서 ID 확인)을 텍스트 편집기로 연다.
2. 앱에서 아무것도 안 고친 채 텍스트 편집기에서 고치고 저장 → 앱 창을 클릭: 묻지 않고 새 내용으로 바뀐다(커서 위치 유지).
3. 앱에서 한 줄 쓰고 1초 안에 텍스트 편집기로 가서 고치고 저장 → 앱 창 클릭: "파일이 앱 밖에서 바뀌었어요" 창. 두 버튼 다 써 보고, `snapshots/<회차ID>/`에 `-conflict.md`(앱 쪽), `-external.md`(바깥 쪽, 앱 쪽을 골랐을 때)가 남는지 본다.
